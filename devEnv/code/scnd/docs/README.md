# Documentation Overview

This folder aggregates non-source deliverables for the assignment:

- `ai_log.md` – prompts/responses plus rationale when using the assistant.
- `build_notes.md` – optional space for multilib setup, cross-compilation steps, or Raspberry Pi specifics.
- `reflection.md` – discussion about compile vs. link failures, interface design, and lessons learned.

Primary usage instructions live in the repo root `README.md`; this directory stores the supporting evidence referenced there.
