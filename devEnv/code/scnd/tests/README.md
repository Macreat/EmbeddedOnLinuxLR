# Tests & Logs

Store runtime logs and binary inspection output here:

- `sample_run.log` – controller output for a deterministic run (`./build/ctl64 65 40`).
- `ctl64.file.txt`, `ctl64.readelf.txt` – inspection output captured with `file` and `readelf -h`.

Update this README when adding more scenarios (e.g., randomized sensor feeds or hardware-in-the-loop tests on Raspberry Pi).
